# About Jibo Revival Group
JRG (Jibo Revival Group) is a group focused on bringing Jibo's original functionality back. We try to enable all of the features Jibo previously had along with creating new features ourselves. We are fully FOSS, and community built.

For information on how you can mod your own Jibo use our guide at [jibo.guide](https://jibo.guide)

Due to our FOSS nature, we allow anybody to contribute to the project. If you'd like to contribute you should go to [our discord](https://discord.gg/CBVJzkRGwN) to get details on how to contribute, and where to contribute.
